# GuideBook.lk

🎓 Group Project for Web Application Development Module

 🚀 Proud to present Guidbook.lk - a location-based web application designed to help users find nearby schools, hospitals, fuel stations, and restaurants with ease.
Built with PHP, this project reflects our shared passion for solving real-world problems through practical web solutions.

💡 Key Features:
Location-based search
User-friendly interface
Fast and responsive design

📌 Technologies used: PHP, MySQL, HTML/CSS, JavaScript
📌 Purpose: Simplifying local discovery for everyone, everywhere.
